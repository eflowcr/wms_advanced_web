Qué resuelve, y cuándo NO usarlo

Qué resuelve

Es el único camino legítimo para poner texto con estilo del sistema. Una variante fija las tres cosas a la vez —tamaño, peso e interlineado— y además decide qué elemento se renderiza.

Existe para que la jerarquía visual y la estructura del documento no se puedan separar: variant="h2" se ve como un H2 y es un <h2>. Siempre. Una pantalla que escribe <h2 class="…"> a mano se saltó el sistema, y nada la obliga a que el nivel coincida con lo que se ve.

El corolario incómodo es la funcionalidad: quien navega con lector de pantalla salta de encabezado en encabezado. Un esquema mentido es una pantalla que no se puede recorrer.

Cuándo NO usarlo

  • No existe as. No hay forma de verse como un nivel y ser otro. Se evaluó y se descartó: un escape que se usa siempre deja de ser un escape, y termina rompiendo el esquema con una prop que aparenta que se pensó.
  • Si el nivel que corresponde no se ve como querés, casi seguro no era un encabezado. El caso que motivó el as —el título de una card de KPI, «RECEPCIONES PENDIENTES» sobre un número grande— es una etiqueta, y le toca caption.
  • Para ver la escala, esta no es la página. Los tamaños al natural están en Fundamentos / Tipografía. Acá se documenta el componente.

Variantes

Siete, y son semánticas: nombran para qué sirve el texto, no cuán grande es. Cuatro renderizan encabezados, una renderiza un párrafo y dos renderizan <span> — caption y mono no son encabezados y no deben aparecer en el esquema del documento.

La mayúscula de h4 la aplica el componente con text-transform, nunca el texto del diccionario: un lector de pantalla deletrea una palabra escrita en mayúsculas, y un texto ya capitalizado no se puede volver a capitalizar según el idioma.

Matriz de estados

La matriz de estados no aplica — y se deja escrita igual

<ewms-text>&ngsp;no tiene estados: no hay hover, ni foco, ni deshabilitado. Es un primitivo que renderiza un elemento y se detiene ahí.

Lo que sí varía —y es lo único que este componente existe para acoplar— es el par elemento del documento contra aspecto. Esa es la grilla de abajo: leer una fila de izquierda a derecha es el argumento del componente entero.

@if (state.id === 'element') { {{ tagFor(variant.id) }} } @else { {{ sampleFor(variant.id) }} }

La columna del medio no está escrita: es el tagName que el navegador reportó para cada muestra del bloque de variantes, el mismo que se lista en Anatomía. Si alguien agregara un as, esta columna dejaría de coincidir con la de la izquierda — que es la única manera de que una grilla demuestre un acoplamiento en vez de afirmarlo.

Tamaños

No aplica

No existe size. El tamaño es la variante: no se combinan por separado, y ese es justamente el acoplamiento del que vive el componente. Un size encima de variant sería el as por la puerta de atrás.

La escala completa, a tamaño real y con su contexto de uso, está en Fundamentos / Tipografía.

Contrato para Angular

Entradas

Una sola, variant, y es input.required(). Sin default a propósito: elegir el nivel es la decisión que este componente obliga a tomar, y un valor por omisión la escondería.

Salidas

Ninguna. Es un primitivo de presentación: no hay nada que emitir.

Accesibilidad

  • El elemento renderizado es el nivel semántico. No se agrega role encima: un <h3> ya es un encabezado de nivel 3, y ponerle el rol sólo agrega una segunda fuente de verdad.
  • caption y mono renderizan <span>: no son encabezados y no aparecen en el esquema.
  • La regla heading-order de axe corre sin filtro de tags en el arnés, así que un nivel saltado revienta la compuerta 5. Donde muerde de verdad es a nivel de página: un componente aislado casi no tiene con qué comparar, y por eso el E2E recorre el showroom entero.
  • Lo que ninguna herramienta ve: si el esquema de una pantalla nueva tiene sentido. El acoplamiento evita que alguien mienta a propósito; no sustituye mirarlo.

Errores comunes

  • Usar h4 como «título chico». Si lo que necesitás es una etiqueta encima de un dato, es caption. El h4 entra al esquema del documento y un lector de pantalla lo va a listar como encabezado.
  • Escribir el texto ya en mayúsculas para el h4. Las pone el CSS. El nodo de texto conserva su capitalización original, que es lo que hace que el lector lo lea como palabra y no letra por letra.
  • Poner <h2 class="text-h2"> a mano porque «es lo mismo». No lo es: ahí nada obliga a que el nivel coincida con el aspecto, y el día que alguien cambie el tamaño la estructura se queda como estaba.

Bloques que no aplican

Dos, y están escritos arriba en lugar de borrados: matriz de estados (el componente no tiene estados) y tamaños (el tamaño es la variante).
